# Lists

Lists are created on the "Family" page. The "Family" page is the base URL with individual lists being sub-paths:

- <base_url>/smith/list_1
- <base_url>/smith/list_2

On the "Family" page is the location where new lists can be created and existing lists deleted. When an existing list is deleted it is deleted from the database after all items are delete from the list first. Logging will provide any historical tracking.
